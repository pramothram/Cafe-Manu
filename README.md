# ☕ Cafe Menu Website

A simple, modern, and responsive café menu website designed to showcase delicious food and beverages in an attractive and user-friendly interface.

## 🌐 Live Demo

[View the Cafe Menu Website](https://cafe-manu.netlify.app?utm_source=chatgpt.com)

## 📌 About the Project

The Cafe Menu website is a frontend web project created to display a café's menu in a clean and visually appealing way. Users can explore different food and beverage items along with their prices.

The project focuses on creating an attractive layout, easy navigation, and a responsive design that works well on different screen sizes.

## ✨ Features

* ☕ Attractive café-themed design
* 📋 Organized food and beverage menu
* 💰 Displays menu item prices
* 🍰 Different menu categories
* 🎨 Clean and modern user interface
* 📱 Fully responsive design
* 💻 Works on desktop, tablet, and mobile devices
* ⚡ Simple and fast user experience

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling and layout design
* **JavaScript** – Interactive functionality
* [Netlify](https://www.netlify.com/?utm_source=chatgpt.com) – Deployment and hosting
